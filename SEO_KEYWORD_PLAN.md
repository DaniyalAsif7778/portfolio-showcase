## Tracking notes

- Treat Mobile and Desktop as separate device segments, not separate on-page keyword lists.
- Compare impressions, clicks, CTR, and average position in Google Search Console's Search results Performance report. Filter country to Pakistan, then compare Mobile and Desktop while reviewing the Queries dimension.
- Search Console reports observed queries and performance; it does not provide a guaranteed rank for a fixed keyword. Search results vary by time, place, device, and searcher context.
- Do not add these phrases as a hidden `meta keywords` list. Google ignores that tag. Use only terms that accurately describe visible page content, headings, titles, project details, and descriptive links.
- This list does not include keyword volumes or claim that any phrase currently ranks. Confirm demand and performance using Search Console after enough impressions accumulate; validate future demand with an actual keyword-planning data source before prioritizing new content.
